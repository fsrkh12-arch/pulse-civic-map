# PULSE — Civic Map

PULSE is a test project for a real-time civic reporting map. It gives residents a clearer way to report and understand local concerns, including road hazards, damaged infrastructure, crowd conditions, local events, and urgent public-safety signals.

## Pilot status

PULSE is currently an exploratory MVP. We are preparing to pitch the concept to relevant government and municipal stakeholders as a possible way to better understand rising citizen concerns about local issues.

PULSE is **not** currently deployed by, partnered with, endorsed by, or integrated with any government agency. It does not dispatch emergency services or contact departments. Future public-sector use would require formal collaboration, privacy and security safeguards, and clearly agreed operating procedures.

## Included prototype features

- Interactive Baku civic map with illustrative reports
- Category filtering and search
- Submit reports at a selected map pin or device location
- Community confirmation signals
- City feed and insights routing guidance
- Browser-local name and surname settings
- SIMA identity verification marked as a future integration; government FIN codes are not collected or stored

## Run locally

Serve the `dist/` folder with any static web server, then open it in a browser.

## Privacy note

This MVP uses illustrative report data. Profile names are saved only in the current browser. Government identity information must not be collected until a secure, authorized identity-verification integration exists.
